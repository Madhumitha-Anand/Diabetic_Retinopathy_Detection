# Diabetic Retinopathy Detection Web App

A lightweight web-based application demonstrating diabetic retinopathy (DR) classification using an interactive interface built with Streamlit.

This project showcases the workflow of an AI-powered medical imaging application, including image upload, processing, and prediction display.

## Features

-  Upload retinal fundus images (JPG, PNG)
-  Real-time image preview
-  Simulated DR severity classification
-  Fast and lightweight (no heavy ML dependencies)
-  Easy deployment with Streamlit Cloud
